# YouHelper v0.1

Бесплатный хелпер для Arizona RP и Rodina Online

## Возможности
- Автоопределение фракции, ранга и имени через /stats
- SmartPDD и SmartUK с облачными базами
- Быстрые команды для всех фракций
- RP отыгровка документов (/spass /slic /smc /sskill)
- PieMenu и FastMenu
- Патруль, авто-доклады, смена кодов сирены
- Все функции бесплатны

## Установка
1. Скачай YouHelper.lua из данного репозитория, или же на сайте nizaev.org 
2. Положи в папку moonloader/
3. Войди в игру и нажми F2
